# NextGen Matrix Workforce

Workforce operations app: jobs and site records, sales leads, finance, reports, compliance, team and announcements.

Built with TanStack Start (React), Supabase and Tailwind. Hosted on Vercel.

## Run locally
1. `cp .env.example .env` and fill in your Supabase values
2. `npm install`
3. `npm run dev`
